API Documentation

POST /v1/chat/completions
OpenAI-compatible chat completion endpoint. Works with any OpenAI SDK.
curl http://localhost:3000/v1/chat/completions \
  -H "Authorization: Bearer sk-blackbox-default" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "blackbox-auto",
    "messages": [{"role": "user", "content": "Hello!"}]
  }'
POST /chat
Simple prompt/response endpoint for quick integrations.
curl -X POST http://localhost:3000/chat \
  -H "Authorization: Bearer sk-blackbox-default" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "What is 2+2?"}'
GET /stats
Get server statistics including cache, queue, and health data.
GET /v1/models
List available models (OpenAI-compatible).

Code Examples

Python (with OpenAI SDK)
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:3000/v1",
    api_key="sk-blackbox-default"
)

response = client.chat.completions.create(
    model="blackbox-auto",
    messages=[{"role": "user", "content": "Hello!"}]
)
print(response.choices[0].message.content)
JavaScript (Node.js)
const OpenAI = require('openai');

const client = new OpenAI({
  baseURL: 'http://localhost:3000/v1',
  apiKey: 'sk-blackbox-default'
});

const response = await client.chat.completions.create({
  model: 'blackbox-auto',
  messages: [{ role: 'user', content: 'Hello!' }]
});
console.log(response.choices[0].message.content);
JavaScript (Fetch)
const response = await fetch('http://localhost:3000/chat', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer sk-blackbox-default',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({ prompt: 'Hello!' })
});
const data = await response.json();
